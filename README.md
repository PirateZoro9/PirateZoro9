## 🚀 Featured Project

### 🎬 [Gatekeeper](https://github.com/PirateZoro9/gatekeeper)
A plugin-based movie & TV discovery app for Android, inspired by Cloudstream's architecture — content providers ship as `.cs3` plugins and load at runtime.

- **Stack:** Kotlin · Jetpack Compose · MVVM · Hilt · OkHttp · Coroutines
- **Highlights:** Runtime plugin system, clean layered architecture (UI → ViewModel → Repository → Plugin), custom scrapers
